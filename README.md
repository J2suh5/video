# 祥 · 睦 —— 夜が明けても、そばにいて

丰川祥子 × 若叶睦的同人动画短片，时长 4 分钟。画面全部由 WebGL 实时渲染，配乐在浏览器里用 WebAudio 实时合成，不依赖任何外部素材文件。

直接用浏览器打开 `index.html`，点「开始放映」即可观看（需要支持 WebGL2 的浏览器，建议戴耳机、全屏横屏）。

## 章节

| 时间 | 章节 | 内容 |
| --- | --- | --- |
| 0:00 | 序 | 星云里两颗相互环绕的光，片名 |
| 0:20 | 壹 · 黄瓜与夕阳 | 童年的夏日黄昏，睦把刚摘的黄瓜递给祥，两人拉钩约定 |
| 1:00 | 贰 · 春日 | 樱花道上祥邀请睦加入乐队；第一次站上舞台 |
| 1:40 | 叁 · 雨夜 | 祥独自站在路灯下，睦撑着伞走过去 |
| 2:20 | 肆 · 假面 | 玫瑰花窗前的假面舞台，提线断裂，面具碎裂 |
| 2:48 | 终 · 星空之下 | 银河与极光下并肩而坐，指尖相触，靠在肩上，直到天亮 |

快捷键：空格 暂停/播放，← → 快退/快进 5 秒，F 全屏，M 静音。进度条上的金色刻度可以直接跳到对应章节。

## 实现

- `src/gl.js` — WebGL2 管线：每个场景一个程序化背景着色器（星云、晚霞、樱花、舞台光束、雨夜城市与积水倒影、玫瑰花窗、银河/极光/流星/黎明），GPU 粒子（花瓣、雨丝、萤火、荧光棒、碎片），二维图层的逆光轮廓光与地面反射，Bloom、色彩分级、暗角、胶片颗粒、镜头雨滴和场景溶解转场。
- `src/art.js` — Canvas2D 绘制的可动剪影人偶：IK 手臂和腿、步行循环、随风摆动的双马尾和长发，侧面/正面/背面三种视角，以及黄瓜、伞、吉他、键盘、面具、樱花树等道具。
- `src/scenes.js` — 每一章的镜头、灯光、角色动作和字幕时间轴。
- `src/audio.js` — 原创配乐（72 BPM，D 大调 → B 小调 → D 小调 → E 大调）。钢琴、八音盒、钟用加法合成预先生成采样，吉他和羽管键琴用 Karplus-Strong 拨弦合成，弦乐、管风琴、贝斯、鼓、雨声、雷声、虫鸣用振荡器和噪声实时生成，带卷积混响和前瞻调度器，画面时钟与音频时钟同步。
- `src/main.js` — 渲染循环、转场、字幕、播放控制。

## 构建与检查

```bash
node tools/build.mjs                 # 把 src/ 内联为 index.html（独立文件）和 sakimutsu.html（Artifact 页面）
node tools/shot.mjs out/ 30 90 205   # 用无头 Chromium 截取指定秒数的画面
node tools/audiotest.mjs out.wav     # 离线渲染各段配乐并输出响度
```

角色出自《BanG Dream! It's MyGO!!!!!》与《BanG Dream! Ave Mujica》。本作为非商业同人作品，旋律、台词与画面均为原创。

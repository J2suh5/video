# 祥 × 睦 —— 雨停之后，春日依旧

一部约 **2 分 03 秒** 的 WebGL 同人动画短片，主角是丰川祥子与若叶睦。
画面全部由 WebGL2 着色器实时绘制，配乐是原创曲，用 Web Audio 合成。项目不使用任何外部图片、模型或音频素材。

> 非官方同人作品。角色版权归 BanG Dream! Project 所有。

## 观看

- **成片视频**：`output/sakiko-mutsumi.mp4`（1920×1080，30fps，H.264 + AAC）
- **实时版**：用 Chrome、Edge 或 Firefox 直接打开 `index.html`（双击即可，不需要服务器），点击「播放」。
  - 快捷键：`空格` 播放/暂停，`←/→` 快退/快进 5 秒，`F` 全屏
  - 显卡较弱时，在地址后加 `?q=720` 或 `?q=540` 降低渲染分辨率

## 技术要点

- `src/gl.js`：WebGL2 小引擎，负责着色器、HDR 帧缓冲和实例化绘制
- `src/shaders.js`：六个场景背景着色器（星云、庭院、夕阳琴键、雨夜街景、哥特舞台、黎明山丘），一个 GPU 粒子着色器（樱花、雨丝、音符、光尘、双螺旋爱心等，位置全部由时间算出），以及剪影精灵着色器（按通道上色并加轮廓光）和后期处理（转场、镜头雨滴、泛光、色调映射、暗角、胶片颗粒）
- `src/figures.js`：用 Canvas2D 矢量绘制角色背影，包括祥子的双马尾螺旋卷、睦的长直发、制服或礼服，以及简单的手臂 IK；还绘制伞、假面、樱枝、黄瓜藤架等道具
- `src/music.js`：原创乐谱，用 OfflineAudioContext 离线合成钢琴、八音盒、Karplus-Strong 吉他与羽管键琴、弦乐垫、管风琴、人声 pad、钟、鼓组和雨声，并输出画面同步要用的音符事件
- `src/scenes.js`：时间轴、各幕编排、转场与调色
- 每一帧都只取决于时间 `t`，所以可以逐帧导出，画面与声音严格同步

## 重新导出视频

依赖：Node.js 18+、[Playwright](https://playwright.dev)（含 Chromium）、ffmpeg。

```bash
node tools/render.mjs --w 1920 --h 1080 --fps 30 --workers 3
# 输出 output/sakiko-mutsumi.mp4；中间帧缓存在 .render/（中断后可续跑）
```

字体（Noto Serif SC、Cormorant Garamond，SIL OFL）已按所用字符子集化，内嵌在 `src/fonts.js` 中。修改文案后，运行 `node tools/fetch-fonts.mjs` 重新生成。

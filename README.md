# 葛立恒数有多大，又有多小

一部用 **WebGL2 实时渲染**的中文科普短片（5 分 20 秒）。从高德纳箭头一路走到 g₆₄，再从葛立恒数走向无穷。

> 有一个数，大到整个可观测宇宙都写不下它；
> 可在另一种意义上，它又小得……几乎微不足道。

## 观看

| 方式 | 说明 |
| --- | --- |
| 直接打开 `index.html` | 双击即可，无需服务器、无需联网。点「播放影片」开始（配乐由浏览器实时合成）。 |
| `dist/graham-number.html` | 所有代码、字体、数据都内联在这一个文件里（约 650 KB），方便分享。 |
| `dist/graham-number-720p.mp4` | 成片预览（1280×720 · 30fps · 含配乐，约 45 MB）。 |
| `npm run render` | 在本机逐帧导出 1920×1080 · 30fps 成片到 `dist/graham-number.mp4`（体积较大，未纳入仓库）。 |

播放器快捷键：`空格` 播放 / 暂停 · `←` `→` 快退 / 快进 5 秒 · `F` 全屏 · `M` 静音 · `C` 字幕。地址后加 `?t=秒数` 可从指定时间开始，例如 `index.html?t=193`。

## 技术

纯手写 WebGL2，不依赖任何第三方库：

- **HDR 管线**：半精度浮点场景缓冲 → 六级双重 Kawase 泛光 → ACES 色调映射 → 暗角、色散、颗粒
- **粒子形变**：65,536 个粒子，位置存在浮点纹理里，在两个形状之间带漩涡地插值；文字形状由离屏 canvas 采样得到
- **四维线框**：实例化的屏幕空间粗线，在顶点着色器里做 4D 旋转和 4D→3D 透视
- **全屏着色器**：星云与星空（可叠加引力透镜黑洞）、数字隧道、递归之塔、传送门、多尺度数轴
- **确定性时间轴**：每一帧只取决于时间 t，所以能随意拖动进度，也能多进程并行逐帧导出
- **配乐**：Web Audio 合成（锯齿波 pad、钟声、低频冲击、噪声上升音），实时播放和离线导出用同一份乐谱
- **字体**：只取片中用到的 579 个字符的子集（思源宋体 / 思源黑体 / Noto Serif Display / JetBrains Mono，SIL OFL），以 base64 内嵌

## 重新生成

```bash
npm install                      # 只需要 playwright（导出视频用）
npm run build                    # 生成单文件 dist/graham-number.html
npm run render                   # 生成 1080p 的 dist/graham-number.mp4（需要 ffmpeg，约 30 分钟）
npm run render -- --from 117 --to 151 --out dist/tower.mp4   # 只导出一段
python3 tools/fetch_fonts.py     # 修改文案后重新子集化字体
```

导出默认用 SwiftShader 软件渲染，任何机器结果一致；有显卡的机器可设 `GPU=1` 加速。

```
tools/                核对数字、生成数据、子集化字体、打包、导出视频
dist/                 单文件版与成片
```
